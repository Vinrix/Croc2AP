# Logic

What each check needs, by stage. Generated by `tools/build_logic.py` from `worlds/croc2/data/logic.json`,
which is written by hand from three walkthroughs (StrategyWiki, the GameFAQs guide by Robshi, and the Croc
fan wiki) matched to the crystal positions in the level files. Do not edit this file; edit logic.json.

Rules of thumb: a smash box needs Butt Stomp; a High Jump needs Butt Stomp as well; a better jelly works on
a lesser marker; carrying and throwing an object needs Power Gloves. Where the guides did not settle
a point the stricter reading is used, so a seed can ask for more than is needed but never less.
